# PokéDex Explorer

App móvil hecha con **React Native + Expo** que consume la [PokéAPI](https://pokeapi.co/).
Taller *Consumo de API con React Native y Expo*, materia Desarrollo Móvil, Tecnológico de Antioquia.

> 🚧 En construcción. El README completo (arquitectura y decisiones) se agrega en la última parte del taller.

## Cómo ejecutarlo

```bash
npm install
npx expo start
```

Escanea el QR con **Expo Go**, o presiona `a` (emulador Android) o `i` (simulador iOS).
